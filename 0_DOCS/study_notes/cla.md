# Carry Lookahead Adder (CLA)

## 배경
- [[adder]]의 RCA는 캐리가 순차 전파되어 비트 폭에 비례해 지연이 증가
- CLA는 각 자리의 캐리를 **이전 자리를 기다리지 않고 미리 계산**해서 지연을 줄임

## Generate / Propagate
각 비트 자리마다 두 신호를 정의:

| 신호 | 정의 | 의미 |
|:--|:--|:--|
| Generate `Gi` | `Ai & Bi` | 이 자리에서 캐리가 새로 생성됨 |
| Propagate `Pi` | `Ai ^ Bi` | 이 자리가 입력 캐리를 다음으로 전달함 |

캐리 점화식:
```
C1 = G0 + P0·C0
C2 = G1 + P1·G0 + P1·P0·C0
C3 = G2 + P2·G1 + P2·P1·G0 + P2·P1·P0·C0
...
```
→ 각 `Ci`가 논리곱/논리합만으로 **동시에** 계산 가능 (이전 캐리를 순차적으로 기다리지 않음)

## 트레이드오프
| 항목 | RCA | CLA |
|:--|:--|:--|
| 지연시간 | O(N) | O(log N) 근사 |
| 게이트 수 / 면적 | 적음 | 많음 (G/P 계산 + 캐리 트리) |
| 설계 복잡도 | 단순 | 상대적으로 복잡 |

## Verilog 구현 포인트
- 4비트 단위로 CLA 블록을 만들고, 여러 블록을 계층적으로 묶는 **블록 CLA(Block CLA)** 구조가 일반적
- 비트 폭이 아주 커지면(32비트 이상) CLA도 트리 깊이가 늘어나므로, 실제로는 CLA 블록 + RCA를 섞은 하이브리드 구조도 많이 씀
